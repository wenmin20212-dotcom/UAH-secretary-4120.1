## 0.1.4 新增

Agent 登记按钮及 agent_registry 工具：分析安装目录、确认登记、查询已知 Agent。登记不代表在线连接、授权或派工。旧包缺少永久身份时明确显示缺口，不从名称猜编号。

保留邮件起草、To/Cc/Bcc、附件快照、本人在原生窗口确认后发送，以及应用内升级提示。Gmail 账号授权由使用者本人完成。

## 从 0.1.3 升级

退出秘书，把本次 Upgrade ZIP 解压到程序目录之外，运行 升级.cmd，填写现有安装目录和外部备份目录。校验原产品、版本及程序文件后完整备份，只更新程序。保留模型设置、聊天、知识、技能、工作区和 Gmail 授权；继续使用原快捷方式。不匹配的旧版不能直接套用。

GitHub 上传不等于公开稳定更新通道已推送；本次不自动安装到你的电脑。完整程序 ZIP 可用于新安装试用，首次使用需配置自己的模型与账号，不要用它覆盖旧资料。

源代码不含运行时二进制、模型凭据、邮箱令牌或聊天；来源为 UAH-incubator 0.9.5 的通用登记、连接器及更新组件。详见 docs/0.1.4-upgrade.md。九视图依然是岗位设计原型，结构检查不代表全部专业流程自动实现。
