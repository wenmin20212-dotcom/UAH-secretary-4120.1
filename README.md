# 私人公司对外联络秘书 — ESCO 4120.1

独立 Windows 桌面 Agent 设计原型，版本 0.1.0。ESCO 4120.1（secretary），ISCO 4120；使用本地 ESCO v1.2.1 原始标准。

## 下载与运行

从本仓库 Releases 下载 `private-company-secretary-0.1.0.zip`，完整解压到可写目录，双击 `启动.cmd`。压缩包包含桌面宿主和 Node 运行环境；Git 源码下载不包含这些二进制依赖。

首次使用须配置自己的模型账号。公司名称、签名、沟通语言、邮箱服务和发送权限待配置。目前没有邮箱业务执行链，未读取或发送真实邮件。

## 岗位设计

六项能力：来信整理、商务邮件起草、按授权发送、外部联系跟进、会面协调、沟通归档。六项能力契约通过原 PS1 检查；九视图见 `agent/exports/78c6722e/`，含原始 ESCO 引用、标准、流程、接口需求、空白状态模板和设计边界。

M1 的 ready 仅满足原型打包门槛，使命仍为设计初稿；其他视图 incomplete 表示专业功能与验收尚未完成。工作流程定义尚未自动执行，接口描述不表示连接可用。
