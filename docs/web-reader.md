# 内置网页读取与浏览器续接

公开网页优先调用 `agent_web_read`：Node 内置 HTTP(S) GET，无需 curl、uvx、ddgs 或浏览器进程，不携带账号 Cookie、不执行 JavaScript、不提交表单。返回 HTTP 状态、最终地址、标题、静态正文、链接与时间；网页内容作为不可信资料处理。重定向最多 5 次、总请求限时 20 秒、响应最多 2 MiB、正文最多 24000 字符。不支持网页图片/PDF等二进制解析。需要动态网页、登录或交互时使用独立浏览器。

失败区分 DNS、HTTP、超时、网络、内容类型及响应过大。DNS 无地址时可尝试工具返回的 www 建议地址，但建议不代表已成功读取。不得将浏览器被另一会话持有、缺少外部命令或一个网站地址失败等同于整台电脑无法联网。该功能不是搜索索引服务，也不能保证所有网站、网络运营商或防爬虫限制均可访问。

浏览器连接器 1.2.0 支持由实际持有进程处理明确关闭请求；普通会话退出仅释放自己的浏览器，保留浏览器登录资料。不强制结束用户个人浏览器，不删除正在使用的锁。

验证：`node tools/test-web-read.cjs` 覆盖真实本地 HTTP、真实 MCP 进程、重定向、错误分类、大小限制及凭据拒绝；`node tools/test-browser-cross-session.cjs` 覆盖两个真实浏览器连接器进程的接手。本次本机秘书连接器实际读取 www.sagewritepress.com 返回 200，独立浏览器也取得页面快照。测试未调用真实模型或发送邮件。

本功能包含于秘书 0.1.5，安装及升级见 docs/0.1.5-upgrade.md。
