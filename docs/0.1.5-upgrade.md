# 秘书 0.1.5 — 浏览器续接与内置网页读取

日期：2026-10-18。Windows 10/11 x64。

- 浏览器连接器 1.2.0：电脑端与手机端协调正常关闭和接手，避免误报 browser_closed；退出无持有权的会话不会误关另一会话浏览器，保留登录资料。
- 新增 agent_web_read：内置 HTTP(S) 只读获取公开网页的静态正文、标题和链接，无需 curl、uvx 或 ddgs。区分 DNS、HTTP、超时和浏览器占用。动态网页、登录和交互使用独立浏览器；不保证绕过网站验证或网络限制。
- 修复子机继承旧话题脚本导致 reading observe 的界面问题。
- 保留 Agent 登记、邮件起草、附件、抄送/密送、原生确认发送及已有更新界面。未扩大 Gmail 授权，模型没有直接发送工具。

## 下载与升级

新安装下载 UAH-Secretary-4120.1-0.1.5-win-x64-Setup.exe，内含桌面宿主、后端、Node 和依赖；自动创建桌面和开始菜单快捷方式，首次配置自己的模型与账号。程序可独立运行，无需孵化师。

旧用户按原版本下载 0.1.3-to-0.1.5 或 0.1.4-to-0.1.5 的 Upgrade.zip。正常退出秘书并停止使用它的手机聊天服务，将包完整解压到原程序目录之外，运行 Upgrade.cmd，填写原安装目录及外部备份目录。升级会核对产品、版本和程序哈希，先完整备份，再只替换程序；保留模型设置、聊天、知识、技能、工作区、Gmail 授权及浏览器资料。未知程序修改会停止覆盖。本机已有网页修复补丁的 0.1.3 也支持。完成后沿用原快捷方式，重新启动手机服务。请勿用新安装目录或直接解压覆盖代替原位置升级。

两个升级包须匹配原版本；更早版本不能直接套用。GitHub Release 发布不等于公开稳定签名更新通道已推送，本版通过上述升级包安装。原标签及附件不覆盖。完整安装包不包含模型、邮箱令牌、聊天或用户工作资料。
