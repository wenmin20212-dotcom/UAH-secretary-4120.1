# 秘书 0.1.7 · Google 文档连接器

新增按需装配的 Google Drive / Docs 连接器：查找、读取、创建、追加和上传；支持 Word 导入原生 Google 文档。系统浏览器本人授权，默认 drive.file，仅应用文件；全盘只读需另行授权。没有分享、删除功能，也没有全盘写权限。

在电脑查找用户指定 Word 后，先复制到本实例 workspace，原件不动，上传时 convertToGoogleDoc:true，返回云端链接。

完整 Setup.exe 用于新电脑安装。已有用户退出本 Agent、停止手机服务，下载上一版到本版的 Upgrade.zip，解压到程序目录之外，运行 Upgrade.cmd，指定原安装目录及外部备份位置。升级包保留职业九视图、模型、账号授权、聊天和工作区；程序哈希不匹配时停止，不覆盖未知改动。已安装本机 Google 连接器热补丁的秘书也有显式匹配支持。不要用完整安装包覆盖旧目录。

首次使用需配置实例自己的 Google Desktop OAuth 客户端，启用 Drive API / Docs API 并由用户本人同意。Gmail 授权不等于文档授权。详见 [Google 文档说明](../google-workspace.md)。

验证覆盖模拟 Google 请求、真实本机回调、DPAPI、M7 规划、脱模装配、MCP 工具及原 Gmail 回归；真实账号和实际云端 Word 排版未自动验收。程序窗口健康不等于模型或专业能力验收。
